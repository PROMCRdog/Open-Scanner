# v0.1.0 independent review

Date: 2026-07-31

## Decision

The final independent read-only review found no remaining actionable static issue in the v0.1.0 candidate. The independent-verifier source gate is resolved.

The review covered the Field Console navigation and sizing, separate Spectrum workspace, timestamp-accurate and stale-aware history, bounded in-memory retention, spectrum-width truthfulness, deterministic physical-Wi-Fi evidence, pause/stop/request serialization, current blocked-state recovery, reactive diagnostics dialogs, exact export preview, privacy boundaries, tests, build evidence, and Git hygiene.

## Review-driven corrections

- Cached radio results now refresh connection evidence and each row's connected marker together.
- A single lock prevents scan-result, scan-request, error, blocked, pause, and stop transitions from publishing contradictory state.
- The tracker uses source timestamps, ends its window at real current elapsed time, shows stale gaps, and explicitly reports an empty retained history.
- Histories are pruned by the UI clock even while scanning is paused and are globally capped.
- Multiple physical Wi-Fi transports are matched to Android's reported primary BSSID; ambiguous evidence is withheld.
- Unknown spectrum width is not invented, and 20/40/80/160/320 MHz geometry remains proportional.
- Blocking states override cached analysis screens, open diagnostic dialogs react to state changes, and stale connection fields are withheld.
- Long network lists and export previews are scrollable; the exact shared payload is previewed.

## Residual physical gate

This decision is static, not a physical-device certification. Xiaomi/HyperOS still rejects standard ADB installation with `INSTALL_FAILED_USER_RESTRICTED`. The final `v0.1.0` tag remains blocked until the owner enables the normal **Install via USB** path and the instrumentation, native screenshots, large-text/accessibility checks, real connection edge cases, and end-to-end interactions are completed with a five-second wait after every tap.
