# Open Scanner v0.2.1 — Scalable Spectrum display

> Candidate release notes. v0.2.1 is not yet published.

Open Scanner v0.2.1 is an explicitly scoped early public release that removes the Spectrum chart's fixed four-network limit and adds control over which observed access points are drawn.

## What is new

- Every AP in the selected channel group is shown by default.
- The new Displayed networks selector reports the exact shown/total count and supports individual curve toggles, Show all, and Only focused.
- The same selector now has a separate radio control for choosing exactly one focused AP. A `FOCUS · ONE` heading, cyan focused row and badge, and muted but still selectable alternative radios make the single-choice rule clear; focus selection never changes the device's Wi-Fi connection.
- The focused AP is always kept on the chart so its curve, selected-AP summary, and overlap result remain aligned.
- Dense charts use scalable visual roles: focus is cyan, Android's current Wi-Fi connection is green, and other displayed APs are subdued. A green peak marker preserves connection status when the focused and connected AP are the same.
- The Current Wi-Fi badge from Scan is repeated in the Spectrum selector and Track network picker.
- For bonded channels, the chart distinguishes the primary channel from the wider footprint center with a dashed marker and explicit MHz copy. A channel-149 AP therefore remains visibly identified as primary channel 149 even when its 40/80/160 MHz footprint has a different center.
- Hiding a curve changes only the chart. Overlap analysis continues using the complete observed snapshot, and the selector discloses that behavior.
- English and Simplified Chinese UI and documentation cover the new workflow.

## Privacy and safety boundary

- Display choices are in-memory UI state and are not exported or persisted as network identifiers.
- No permission, `INTERNET` access, telemetry, scan cadence, background work, or connection behavior changed.
- The chart remains a visualization of Android scan metadata and RSSI, not a frequency-resolved RF spectrum measurement.
