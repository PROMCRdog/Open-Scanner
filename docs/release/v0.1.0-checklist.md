# v0.1.0 release checklist

Status: statically verified release candidate; final tag blocked on physical install/runtime QA.

## Build and source

- [x] Public history begins with a scoped, sanitized source snapshot.
- [x] Public source excludes private captures, proprietary prototype material, signing material, and machine-specific paths.
- [x] Gradle wrapper version and SHA-256 pinned.
- [x] Stable JDK/AGP/Kotlin/Compose/SDK set recorded in ADR 0002.
- [x] Debug APK and instrumentation APK assemble.
- [x] Release APK, lint, and strict dependency verification pass under JDK 17.

## Product

- [x] Selected Field Console direction recorded.
- [x] Separate Spectrum tab retained by explicit user request.
- [x] Five labelled, 48 dp top-level destinations.
- [x] Permission, Wi-Fi off, Location off, unsupported, checking, and safe-error states.

- [x] 2.4/5/6 GHz selection and passive overlap graph.

- [x] Privacy Mode and redacted JSON/CSV preview/share.

- [x] Threat model, security policy, contribution policy, and license present.
- [x] Release APK permission/component and forbidden-endpoint scan captured.

## Verification

- [x] Pure JVM domain/privacy/export tests pass.
- [x] Compose instrumentation tests compile.
- [ ] Compose instrumentation tests run on the connected physical device.
- [ ] Native screenshots inspected against the selected visual reference.
- [ ] Every automated device tap followed by a five-second response wait.
- [x] Independent final verifier findings resolved.
- [ ] Annotated `v0.1.0` release tag created and pushed after physical-device QA.
