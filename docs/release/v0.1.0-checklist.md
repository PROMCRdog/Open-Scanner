# v0.1.0 release checklist

Status: signed public release candidate with bounded API 37 compatibility QA; final tag remains blocked on the supported-device, accessibility, and performance matrix.

## Build and source

- [x] Public history begins with a scoped, sanitized source snapshot.
- [x] Public source excludes private captures, proprietary prototype material, signing material, and machine-specific paths.
- [x] Gradle wrapper version and SHA-256 pinned.
- [x] Stable JDK/AGP/Kotlin/Compose/SDK set recorded in ADR 0002.
- [x] Debug APK and instrumentation APK assemble.
- [x] Release APK, lint, and strict dependency verification pass under JDK 17.

## Product

- [x] Selected Field Console direction recorded.
- [x] Separate Spectrum tab retained by explicit user request.
- [x] Five labelled, 48 dp top-level destinations.
- [x] Permission, Wi-Fi off, Location off, unsupported, checking, and safe-error states.
- [x] Real shared Wi-Fi snapshot pipeline with bounded tracker history.
- [x] 2.4/5/6 GHz selection and passive overlap graph.
- [x] Local Android connection evidence and system-owned settings routes.
- [x] Privacy Mode plus redacted-by-default JSON/CSV preview/share.
- [x] Explicit opt-in unredacted reports with warning, labelled exact preview, and per-share confirmation.

## Privacy and security

- [x] No `INTERNET` permission or external endpoint.
- [x] Backup disabled; cleartext disabled; no implicit/background raw scan logging.
- [x] Raw identifiers excluded from default exports by tests.
- [x] Threat model, security policy, contribution policy, and license present.
- [x] Release APK permission/component and forbidden-endpoint scan captured.

## Verification

- [x] Pure JVM domain/privacy/export tests pass.
- [x] Compose instrumentation tests compile.
- [x] Nine Compose instrumentation tests run on one connected API 37 physical device.
- [ ] Native screenshots inspected across every destination and required display/accessibility mode. Track and Settings passed a bounded dark-mode inspection; the remaining capture run was interrupted by the device lock screen.
- [x] Every direct ADB tap used during the bounded release check was followed by a five-second response wait.
- [ ] At least two supported API 26–36 physical-device classes complete the release matrix.
- [ ] Permission grant/denial/revocation, rotation/multi-window, light/dark, RTL, 200% text, TalkBack, Switch Access, and reduced motion complete on physical devices.
- [ ] Foreground/background performance and battery budgets complete against the documented baseline.
- [x] Independent final verifier findings resolved.
- [ ] Annotated `v0.1.0` release tag created and pushed after all physical-device gates pass.
