# v0.2.0 release checklist

Status: **not release-ready**. Language-selector code revision `97da15b` has passed 112 JVM tests, all 15 emulator instrumentation tests, release lint, package-boundary review, and a manual API 36 emulator language flow. The previously signed candidate predates this change and is superseded. A fresh independent review, final cache-independent gate, replacement signed candidate, CI, and the full unlocked OPPO cadence/lifecycle/migration/report-flow protocol remain required before publication.

This checklist applies the early public release policy in [ADR 0003](../adr/0003-early-public-release-policy.md) to the conditional fast-refresh decision in [ADR 0004](../adr/0004-conditional-fast-scan-cadence.md). A checked documentation item is not evidence that the corresponding runtime behavior passed.

## Decision and documentation baseline

- [x] Five-second mode is defined as a foreground request cadence, not a guaranteed hardware scan cadence.
- [x] Supported values are fixed at 5, 10, 15, 30, and 60 seconds; 30 seconds remains the default/fallback and no one-second mode is included.
- [x] Eligibility requires an explicitly discovered throttle-off state; throttle-on and unavailable states disable five seconds.
- [x] A saved five-second value automatically resets to 30 seconds after capability discovery if it becomes ineligible.
- [x] The scope excludes new permissions, `INTERNET`, a background service/worker, wake locks, and a second scan loop.
- [x] Settings offers System default, English, and Simplified Chinese; System default is the clean-install/reset choice and tracks later device-language changes.
- [x] The English and Simplified Chinese documentation baselines describe the selector and no longer describe localization as future work.

## Implementation and automated/static evidence

- [x] Version is `2` / `0.2.0`, and About reads `BuildConfig.VERSION_NAME`.
- [x] Preference validation accepts only the five supported values and resets every other persisted value to 30 seconds.
- [x] One monotonic scheduler enforces one in-flight request, coalesces manual refresh, recovers after 15 seconds, reschedules after relevant state changes, and stops outside the foreground.
- [x] Fresh broadcasts advance observation identity/history; rejected, non-updated, unchanged, cached, and timed-out cycles do not create new samples.
- [x] Five-second eligibility, accessible unavailable explanations, battery/OEM warning, and automatic 30-second fallback are present in English and Simplified Chinese.
- [x] All 112 JVM tests pass and cover cadence, timeout, overlap prevention, coalescing, lifecycle stop/resume, eligibility, delayed capability discovery, fallback, serialized publication, truthful freshness, EN/zh resource parity, localized search, explicit hidden-SSID semantics, and locale-tag policy.
- [x] All 15 Compose instrumentation tests pass on an Android 16 / API 36 emulator, covering five seconds enabled/disabled states, language options/default callback, dynamic version copy, and accessibility semantics.
- [x] A clean API 36 emulator flow verifies empty locale override on install, immediate English/Chinese switching, Chinese cold-restart persistence, System default following later device-language changes in both directions, and reset clearing the override. Every direct emulator UI tap was followed by five seconds.
- [ ] Strict JVM tests, debug assembly, instrumentation assembly, release lint, and unsigned release assembly pass together with every task rerun without the build cache on the final code revision.
- [x] `git diff --check` passes on the intended branch diff.
- [ ] Fresh independent read-only follow-up accepts the selector, dependency/manifest boundary, evidence, and replacement signed candidate with no remaining P0-P3 findings.
- [x] Packaged manifest/component audit confirms no new permission or `INTERNET`, no enabled/exported background service, worker, alarm, or scan component, and only a disabled non-exported AndroidX locale metadata holder service.
- [x] Dependency review confirms that fast refresh still adds no dependency; the language selector adds pinned AppCompat 1.7.1 and explicitly declares the already-resolved Startup 1.1.1 manifest runtime with strict hash verification.
- [x] The unused EmojiCompat initializer is removed from the merged manifest, avoiding its font-provider query and deferred background initialization.

## Physical-device QA

No Android device was attached when this record was opened. An authorized OPPO PMA120 running Android 16 / API 36 later connected with the permanent release lineage installed, and the pre-selector candidate installed and cold-started. That artifact is now historical and superseded. The OPPO has not been used for the selector build; the emulator gate must remain complete before installing a replacement signed candidate.

- [ ] On an authorized Android 10+ device, throttle ON leaves five seconds visible but disabled with the correct explanation.
- [ ] After throttle OFF, five seconds can be selected and a two-minute redacted request/source-age trace is captured.
- [ ] The trace demonstrates one request at a time and distinguishes fresh timestamps from cached/reused evidence; it does not need to demonstrate a fresh hardware result every five seconds.
- [ ] Switching throttle back ON automatically persists and schedules 30 seconds.
- [ ] Pause/resume, background/foreground, process restart, timeout recovery, and manual-refresh coalescing are exercised without crash or ANR.
- [ ] Upgrade installation from the permanently signed v0.1.0 artifact preserves the expected signing lineage and safely migrates preferences.
- [ ] On OPPO, Settings visibly offers System default, English, and Simplified Chinese; switching, cold-restart persistence, and reset-to-system-default work with five seconds after every tap.
- [ ] Battery/performance observations are recorded with the device, OS, duration, and actual result cadence disclosed.
- [ ] Every direct device UI tap is followed by a five-second response wait.
