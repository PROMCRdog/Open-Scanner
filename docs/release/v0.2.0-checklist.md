# v0.2.0 release checklist

Status: **published and verified.** The selector-inclusive code, final strict build, independent review, permanent signing, exact-candidate OPPO protocol, pull-request and merged-main CI, annotated tag, release upload, and fresh public-download verification have passed within the bounded scope below.

This checklist applies the early public release policy in [ADR 0003](../adr/0003-early-public-release-policy.md) to the conditional fast-refresh decision in [ADR 0004](../adr/0004-conditional-fast-scan-cadence.md). A checked item is backed by the bounded evidence in [v0.2.0-test-evidence.md](v0.2.0-test-evidence.md); it is not a claim of broad device certification.

## Decision and documentation baseline

- [x] Five-second mode is defined as a foreground request cadence, not a guaranteed hardware scan cadence.
- [x] Supported values are fixed at 5, 10, 15, 30, and 60 seconds; 30 seconds remains the default/fallback and no one-second mode is included.
- [x] Eligibility requires an explicitly discovered throttle-off state; throttle-on and unavailable states disable five seconds.
- [x] A saved five-second value automatically resets to 30 seconds after capability discovery if it becomes ineligible.
- [x] The scope excludes new permissions, `INTERNET`, a background service/worker, wake locks, and a second scan loop.
- [x] Settings offers System default, English, and Simplified Chinese; System default is the clean-install/reset choice and tracks later device-language changes.
- [x] English and Simplified Chinese documentation describe the selector and truthful five-second behavior.

## Physical-device QA

The authorized test device was an OPPO PMA120 running Android 16 / API 36. Every direct device UI tap was followed by a five-second response wait.

- [x] Throttle ON leaves five seconds visible but disabled with the correct localized and accessible explanation.
- [x] With the actual ColorOS Developer-option throttle switched OFF, five seconds is selectable and a 155,013 ms redacted request/source-age trace is captured.
- [x] The 33-record trace reports accepted/updated/non-throttled cycles and measured steady deltas of 4,877-5,138 ms (median 5,004 ms) without claiming universal hardware cadence.
- [x] Switching the actual throttle back ON automatically persists and schedules 30 seconds; the Developer-option state was restored.
- [x] Pause/resume, background/foreground, process restart, and manual refresh were exercised without crash or ANR. Physical timeout injection and exact same-in-flight coalescing remain deterministic JVM evidence.
- [x] Upgrade from the permanent-signer v0.1.0 artifact preserves package/signer identity, `firstInstallTime`, and the deliberately seeded privacy/refresh preferences.
- [x] Settings visibly offers System default, English, and Simplified Chinese; switching, cold-restart persistence, direct System-default restoration, and reset-to-system-default work.
- [x] The report-redaction warning is localized and complete; canceling leaves redaction enabled. The redacted exact CSV preview/share-sheet flow passed without selecting an external recipient.
- [x] The short run produced no visible thermal/performance problem; its two-minute duration is disclosed as insufficient for a battery-life claim.
- [x] Final device state is System default language, report redaction on, 30-second refresh, Android throttle on/default, with the exact signed candidate installed.
