# Support

Open Scanner is a community-maintained project and support is provided on a best-effort basis.

- Use the [bug report form](https://github.com/PROMCRdog/Open-Scanner/issues/new?template=bug_report.yml) for reproducible defects.
- Use the [feature request form](https://github.com/PROMCRdog/Open-Scanner/issues/new?template=feature_request.yml) for product proposals.
- Use a [private security advisory](https://github.com/PROMCRdog/Open-Scanner/security/advisories/new) for suspected vulnerabilities.

Search existing issues before opening a new one. Include the affected commit, Android version, permission state, expected result, actual result, and a minimal reproduction.

Never post real SSIDs, BSSIDs, IP addresses, device identifiers, credentials, raw device dumps, or unredacted screenshots. Replace them with synthetic values before sharing evidence.
